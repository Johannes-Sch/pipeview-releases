# PipeView — Downloads

Official download page for **PipeView**, a free HL7v2 message viewer and reference tool for Windows and Android.

➡️ **[Download the latest release](https://github.com/Johannes-Sch/pipeview-releases/releases/latest)**

This repository hosts the released builds only. PipeView is closed-source; the source code is not published here.

## What is PipeView?

PipeView parses, visualizes, navigates, and validates HL7v2 messages and includes an offline reference for HL7 segments, fields, data types, tables, and message structures (HL7 v2.1–2.7.1). It works fully offline; message content is processed locally on your device.

## Downloads

Each release attaches:
- **Windows** — `PipeView-<version>-windows-x64.exe` (portable, no installer)
- **Android** — `PipeView-<version>-android.apk` (sideload)

### Install notes
- **Windows:** The executable is portable — just run it. As a new, unsigned app it may trigger a Windows SmartScreen warning the first few times ("More info" → "Run anyway"); this fades as download reputation builds.
- **Android:** Installing an APK outside the Play Store requires allowing installs from your browser/file manager ("unknown sources").

## ⚠️ Not a medical device

PipeView is a developer, integration, and educational tool. It is **not** a medical device (EU MDR 2017/745) and is **not** intended for diagnosis, treatment, clinical decision-making, or patient care. Do not rely on its output for any clinical or safety-critical decision.

## Privacy

PipeView processes message content locally on your device and does not transmit it to any server. You remain responsible for handling any real patient data in line with applicable data-protection law (GDPR/DSGVO, HIPAA, etc.).
